# ICC Solutions website and helpdesks: design preview

A preview of a proposed new ICC Solutions website (`index.html`), helpdesk (`helpdesk/index.html`) and VIABLE helpdesk
(`viable-helpdesk/index.html`). It is not the live site. The live site is https://www.iccsolutions.com.

- Every page carries a small tag saying it is a preview, and asks search engines not to list it.
- The enquiry form and the two ticket forms send nothing.
- The VIABLE helpdesk's testing and certification guide is here without its PDF until ICC confirms it can be public.
- The ICC helpdesk's getting started guide, and its PDF, are a draft for ICC to check.
- `try/` is Try a test run, a working copy of ICCSimTMat's screens with demo tests, for ICC to look at. The website links to it from
  the home page and the POS & ATM testing page.
- Built on 23 November 2026 from website v2.42.0, helpdesk v1.7.0, VIABLE helpdesk v1.5.0 and Try a test run v2.7.0.
- Earlier versions are kept, each in a folder named after it: `v2.20.0/`, `v2.28.0/`.
